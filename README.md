## About

에너지 서비스의 프론트엔드 개발과 고객사별 배포를 맡아왔으며, 현재는 온프레미스·클라우드 환경의 서버 구축과 운영을 담당하고 있습니다. 제조·재고 관리 서비스의 프론트엔드 유지보수도 병행하고 있습니다.

고객의 업무 절차를 이해하고 화면과 기능에 반영하는 일을 해왔습니다. 직접 개발한 기능뿐 아니라 다른 팀의 작업도 함께 조율하며, 현장에서 동작을 확인하고 운영에 반영하는 과정까지 경험했습니다.

- **Frontend** — React·TypeScript 기반 업무 화면, API 연동, 대시보드 성능 개선
- **Delivery & Operations** — 고객사별 웹 배포, Linux 서비스 구성, 운영 점검과 로그 관리
- **Collaboration** — Figma·Zeplin 디자인 협업, 요구사항 구체화, 개발 일정 조율과 결과 검증

## Selected Experience

### 에너지 플랫폼 프론트엔드

React 기반 대시보드와 관제 화면을 개발했습니다. 초기 조회 범위를 조정하고 비필수 데이터의 조회를 늦추는 방식으로 로딩 흐름을 개선했습니다. 웹사이트 개발에서는 디자인 사양과 에셋을 확인해 화면을 구현하고 API·차트를 연동했습니다.

### 제조·재고 관리 서비스 유지보수

운영 중인 기존 서비스의 입력·조회·저장 흐름을 분석해 오류를 수정했습니다. 입고와 불출 데이터의 연결, 기존 품목의 수정 처리, 검색 조건 유지와 다운로드 범위 등 실제 사용 과정에서 발생한 문제를 다뤘습니다.

### 폐쇄망 구축과 서비스 운영

기존 서버의 프로세스와 서비스 설정을 조사해 신규 환경을 구성했습니다. 폐쇄망 설치 과정의 의존성 오류를 해결하고 서비스 기동과 데이터 반영을 확인했습니다. 이후 배포, 정기 점검, 로그 저장 경로와 로테이션 정비를 맡았습니다.
